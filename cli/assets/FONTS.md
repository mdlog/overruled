# Fonts embedded in case.html
These files are subset to Latin from the Debian packages and embedded as base64, so the case page works offline.

- garamond-*.woff2 — EB Garamond (Georg Duffner, Octavio Pardo). SIL Open Font License 1.1.
- mono-*.woff2 — Noto Sans Mono (Google). SIL Open Font License 1.1.
